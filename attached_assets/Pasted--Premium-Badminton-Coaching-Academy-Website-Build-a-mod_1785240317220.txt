# Premium Badminton Coaching Academy Website

Build a **modern, premium, minimalist, production-ready frontend** for a **Badminton Coaching Academy** using:

* React + Vite
* Tailwind CSS
* React Router
* Framer Motion
* Lucide Icons

The code should be **simple, modular, reusable, well-organized, beginner-friendly, and easy to maintain.**

Use clear folder names, reusable components, clean naming conventions, comments only where helpful, and prepare the structure for future backend integration (Supabase/Firebase). Do **not** over-engineer the project.

---

# Design Philosophy

The website should feel inspired by:

* Apple
* Nike
* Linear
* Framer
* Notion

Focus on elegance rather than quantity.

Less content.
More whitespace.
Clean layouts.
Premium typography.
Smooth animations.
Excellent responsiveness.

Avoid clutter.

# Important

Prioritize quality over quantity.

Do not create unnecessary sections.

Do not fill the website with excessive text.

Use generous whitespace.

Keep every section elegant, premium, and visually balanced.

The final website should feel like a modern sports brand rather than a traditional coaching website.

Most importantly, write clean, understandable code that any developer can easily modify in the future.
